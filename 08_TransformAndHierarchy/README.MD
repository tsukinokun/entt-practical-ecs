# 08_TransformAndHierarchy
このプロジェクトでは、ゲームエンジンにおける最も重要な要素のひとつである**Transform（位置・回転・スケール）** と **親子関係（Hierarchy）** を実装します。

``Transform``は``ECS``の中心的なコンポーネントであり、ローカル座標とワールド座標の概念を理解することが、後の**レンダリング**・**カメラ**・**シーン管理**へとつながる基礎になります。

## 📘 学べること
- ``Transform``の設計 
- 親 → 子 への``Transform``の継承（ローカル → ワールド）  
- ``dirty``フラグによる遅延更新
- 親子関係の管理方法 
- ``TransformSystem``による階層構造の更新処理
