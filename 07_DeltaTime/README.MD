# 07_DeltaTime
このプロジェクトでは、**DeltaTime（経過時間）を用いてフレームレートに依存しない更新処理**を実装します。

ゲームは環境によってフレームレートが変動するため、**1 フレームあたりの経過時間**を使って処理を補正する必要があります。  

``DeltaTime``はそのための重要な仕組みです。

## 📘 学べること
- `std::chrono::steady_clock`を使った時間計測
- 前フレームからの経過時間``DeltaTime``の算出
- `deltaTime` を用いた位置更新の補正
- フレームレートが変動しても安定した動作を実現する方法
