# 09_Event
このプロジェクトでは、``ECS``と相性の良い**イベント駆動（Event-Driven）アーキテクチャ** を学びます。
イベントを使うことで、システム同士の依存を減らし、拡張しやすいゲームロジックを構築できます。

本章では、シンプルな **EventBus** を実装し、``イベントの発行（publish）``/``購読（subscribe）``/``処理（dispatch）``の流れを理解します。

## 📘 学べること
- ``EventBus``の基本構造 
- イベント型ごとの``ハンドラ登録``（``subscribe``）  
- ``publish``によるイベントの蓄積（遅延処理）
- ``dispatch``によるイベントの一括処理  
- システム間の疎結合化  
- ``ECS``とイベント駆動の連携方法
